# 구성원 성과 자가점검 · 고과 순위산정 시스템 (오프라인)

인터넷 연결 없이 Excel과 HTML 파일만으로 동작하는 성과 고과 순위산정 도구입니다.

## 구성 파일

| 파일 | 역할 |
|---|---|
| `성과_고과_시스템.xlsx` | **관리자/HR 전용** 마스터 워크북. 전 구성원 시트, 팀장 정성평가, 동료추천 집계, 점수 계산 및 순위산정을 모두 포함합니다. 구성원에게 그대로 배포하지 마세요 — 다른 사람의 데이터와 최종 순위까지 함께 보입니다. |
| `구성원_배포용/자가점검표_<이름>.xlsx` | **구성원 개인 배포용** 파일. 본인의 자가점검표 한 장만 담겨 있어 개별로 나눠줘도 다른 사람 정보가 노출되지 않습니다. |
| `구성원_배포용/자가점검표_템플릿(신규구성원용).xlsx` | 새로 합류한 구성원에게 배포할 빈 템플릿 (파란 칸만 있고 값은 비어 있음) |
| `ranking_dashboard.html` | Excel에서 뽑은 결과를 표/그래프로 보여주는 오프라인 대시보드 (브라우저에서 파일을 직접 열면 됨, 서버 불필요) |

## 전체 프로세스

1. **자가점검표 배포 및 작성** — 관리자가 `구성원_배포용/자가점검표_<이름>.xlsx` 파일을 각자에게 나눠줍니다(메일·USB 등 오프라인 경로). 구성원은 자기 파일만 받으므로 다른 사람의 데이터를 볼 수 없습니다. 파란 글자 칸에 본인 성과(What) · 역량(How) · 동료추천(Peer) 내용을 입력한 뒤 파일을 저장해 관리자에게 회신합니다. (새 구성원은 `자가점검표_템플릿(신규구성원용).xlsx`를 사용)
2. **마스터 워크북에 반영** — 관리자가 회신받은 개인 파일의 `자가점검표` 시트에서 B3:B31 범위를 복사해, `성과_고과_시스템.xlsx`의 해당 `자가점검표_<이름>` 시트 B3:B31에 값 붙여넣기(그림 아님, 서식 유지) 합니다. 이 작업은 관리자만 수행합니다.
3. **팀장 정성평가** — 팀장(2차 평가자)이 마스터 워크북의 `팀장_정성평가` 시트에서 구성원별 성과/역량 정성항목에 1~5점을 매깁니다.
4. **자동 병합** — `데이터입력_통합` 시트와 `동료추천_집계` 시트가 각 구성원 시트의 데이터를 수식(`INDIRECT`)으로 자동으로 모읍니다. 이 단계는 마스터 워크북 안에서 완전히 자동으로 이뤄집니다.
5. **점수 계산 및 순위산정** — `계산_순위표` 시트가 성과 60% · 역량 20% · 동료평가 20%(기본값, `파라미터` 시트에서 조정 가능) 가중치로 최종점수와 순위를 계산합니다.
6. **대시보드로 확인** — `계산_순위표` 시트를 CSV로 저장하거나 표를 복사해 `ranking_dashboard.html`에 붙여넣으면 순위/분포 그래프를 볼 수 있습니다.
7. **1:1 리뷰** — 관리자 모드에서 리뷰할 구성원을 선택해 "구성원 모드"로 전환한 뒤 노트북을 구성원에게 보여주고, 함께 회신받은 `자가점검표_<이름>.xlsx` 내용을 참고하며 리뷰합니다. 리뷰가 끝나면 PIN으로 관리자 모드로 복귀합니다.

## 대시보드 보기 모드 (1:1 리뷰용)

`ranking_dashboard.html`은 두 가지 화면을 제공합니다.

- **관리자 모드** (기본) — 전체 구성원의 순위표, 최종점수 비교, 성과/역량/동료 breakdown이 모두 보입니다.
- **구성원 모드** — 관리자가 우측 상단 "구성원 모드로 전환"에서 한 명을 선택하면, 그 사람의 화면(본인 최종점수·순위, 팀 평균/최고 대비 비교, 본인 breakdown)만 표시됩니다. **다른 구성원의 이름이나 점수는 화면 어디에도 나타나지 않습니다** (데이터 원본 붙여넣기 영역 포함).

데이터를 처음 불러오면 관리자 PIN(4자리, 선택)을 설정할 수 있습니다. 설정해두면 구성원 모드에서 관리자 모드로 되돌아갈 때 PIN을 확인하므로, 1:1 도중 노트북을 잠시 구성원에게 맡겨도 실수로 전체 순위표가 노출되지 않습니다.

> **중요**: 이 구분은 화면에 표시되는 내용을 제한하는 **UI 수준의 보기 제한**입니다. 별도 서버·로그인이 없는 단일 HTML 파일이므로, 브라우저 개발자 도구를 사용하면 메모리에 로드된 전체 데이터에 접근할 수 있습니다. 신뢰할 수 있는 사람(관리자 본인)이 노트북을 직접 조작하는 대면 1:1 상황에서 "다른 구성원 점수가 화면에 실수로 보이는 것"을 막는 용도로 설계되었으며, 이는 실제 접근 통제(서버 인증)를 대체하지 않습니다.

## 점수 산식

- **성과환산점수 (100점)** = 기여도(1~10→30점) + 성과도(1~10→30점) + 팀장 정성점수(1~5→40점)
- **역량환산점수 (100점)** = 학점환산(SKHU+mySuni 학점 합, 상한 20학점→40점) + AI 활용 자가점수(1~10→30점) + 팀장 정성점수(1~5→30점)
- **동료환산점수 (100점)** = MIN(추천받은 횟수, 상한 4회) ÷ 4 × 100
- **최종점수** = 성과환산×60% + 역량환산×20% + 동료환산×20%

모든 가중치와 상한값은 `파라미터` 시트의 노란 칸에서 조정할 수 있습니다.

## 신규 구성원 추가

1. `구성원_배포용/자가점검표_템플릿(신규구성원용).xlsx`을 새 구성원에게 배포해 작성받습니다.
2. 마스터 워크북에서 `자가점검표_템플릿` 시트를 복제하고 시트명을 `자가점검표_<이름>` 형식으로 변경한 뒤, 회신받은 개인 파일의 B3:B31 값을 붙여넣습니다.
3. `데이터입력_통합`, `동료추천_집계`, `팀장_정성평가`, `계산_순위표` 표의 마지막 행 아래에 새 행을 추가하고, 이름 칸에 이름을 입력한 뒤 윗 행의 수식을 그대로 복사(드래그)합니다.

## 참고

- 동료 추천 사유, 아쉬운 성과 서술 등 정성 텍스트는 팀장/HR이 평가 시 참고자료로 사용하며, 팀장 정성점수(1~5)로 환산되어 최종 점수에 반영됩니다.
- 워크북에 들어있는 홍길동/김영희/이철수/박민수 데이터는 사용법을 보여주기 위한 예시이며, 실사용 시 모두 교체해야 합니다.
- `구성원_배포용/` 폴더의 개인 파일들도 같은 예시 데이터로 미리 채워져 있어 배포 흐름을 바로 확인해볼 수 있습니다. 실사용 시 각자 본인 내용으로 덮어써야 합니다.
- `ranking_dashboard.html`은 완전히 오프라인으로 동작하며(외부 CDN·네트워크 요청 없음), CSV 파일 업로드 또는 표 붙여넣기 두 가지 방식을 지원합니다.
- 불러온 데이터는 브라우저 탭의 메모리에만 존재하며 저장되지 않습니다. 탭을 닫거나 새로고침하면 사라집니다.
