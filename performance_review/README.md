# 구성원 성과 자가점검 · 고과 순위산정 시스템 (오프라인)

인터넷 연결 없이 Excel과 HTML 파일만으로 동작하는 성과 고과 순위산정 도구입니다.

## 구성 파일

| 파일 | 역할 |
|---|---|
| `성과_고과_시스템.xlsx` | 구성원 자가점검표 입력, 팀장 정성평가, 동료추천 집계, 점수 계산 및 순위산정을 모두 포함하는 워크북 |
| `ranking_dashboard.html` | Excel에서 뽑은 결과를 표/그래프로 보여주는 오프라인 대시보드 (브라우저에서 파일을 직접 열면 됨, 서버 불필요) |

## 전체 프로세스

1. **자가점검표 작성** — 각 구성원이 `자가점검표_템플릿` 시트를 복제해 `자가점검표_<이름>`으로 이름을 바꾸고, 파란 글자 칸에 본인 성과(What) · 역량(How) · 동료추천(Peer) 내용을 입력합니다.
2. **팀장 정성평가** — 팀장(2차 평가자)이 `팀장_정성평가` 시트에서 구성원별 성과/역량 정성항목에 1~5점을 매깁니다.
3. **자동 병합** — `데이터입력_통합` 시트와 `동료추천_집계` 시트가 각 구성원 시트의 데이터를 수식(`INDIRECT`)으로 자동으로 모읍니다. 사람이 수작업으로 복사·붙여넣기 할 필요가 없습니다.
4. **점수 계산 및 순위산정** — `계산_순위표` 시트가 성과 60% · 역량 20% · 동료평가 20%(기본값, `파라미터` 시트에서 조정 가능) 가중치로 최종점수와 순위를 계산합니다.
5. **대시보드로 확인** — `계산_순위표` 시트를 CSV로 저장하거나 표를 복사해 `ranking_dashboard.html`에 붙여넣으면 순위/분포 그래프를 볼 수 있습니다.

## 점수 산식

- **성과환산점수 (100점)** = 기여도(1~10→30점) + 성과도(1~10→30점) + 팀장 정성점수(1~5→40점)
- **역량환산점수 (100점)** = 학점환산(SKHU+mySuni 학점 합, 상한 20학점→40점) + AI 활용 자가점수(1~10→30점) + 팀장 정성점수(1~5→30점)
- **동료환산점수 (100점)** = MIN(추천받은 횟수, 상한 4회) ÷ 4 × 100
- **최종점수** = 성과환산×60% + 역량환산×20% + 동료환산×20%

모든 가중치와 상한값은 `파라미터` 시트의 노란 칸에서 조정할 수 있습니다.

## 신규 구성원 추가

1. `자가점검표_템플릿` 시트를 복제하고 시트명을 `자가점검표_<이름>` 형식으로 변경합니다.
2. `데이터입력_통합`, `동료추천_집계`, `팀장_정성평가`, `계산_순위표` 표의 마지막 행 아래에 새 행을 추가하고, 이름 칸에 이름을 입력한 뒤 윗 행의 수식을 그대로 복사(드래그)합니다.

## 참고

- 동료 추천 사유, 아쉬운 성과 서술 등 정성 텍스트는 팀장/HR이 평가 시 참고자료로 사용하며, 팀장 정성점수(1~5)로 환산되어 최종 점수에 반영됩니다.
- 워크북에 들어있는 홍길동/김영희/이철수/박민수 데이터는 사용법을 보여주기 위한 예시이며, 실사용 시 모두 교체해야 합니다.
- `ranking_dashboard.html`은 완전히 오프라인으로 동작하며(외부 CDN·네트워크 요청 없음), CSV 파일 업로드 또는 표 붙여넣기 두 가지 방식을 지원합니다.
