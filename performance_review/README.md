# 구성원 성과 자가점검 · 고과 순위산정 시스템 (오프라인)

인터넷 연결 없이 Excel과 HTML 파일만으로 동작하는 성과 고과 순위산정 · 1:1 리뷰 도구입니다.
모든 자가점검 항목은 **정량 목표 → 달성 결과 → 자가평가 점수(1~10)** 3단 구조로 통일되어 있어
자가점검표만으로 "자가점검 기준점수"가 자동 계산되고, 여기에 팀장이 자가점수 부풀리기를 막기 위한
소폭 조정점수(-10~+10)를 더해 최종점수를 확정합니다.

## 구성 파일

| 파일 | 역할 |
|---|---|
| `성과_고과_시스템.xlsx` | **관리자/HR 전용** 마스터 워크북. 전 구성원 시트, 동료추천 집계, 점수 계산 및 순위산정을 모두 포함합니다. 구성원에게 그대로 배포하지 마세요 — 다른 사람의 데이터와 최종 순위까지 함께 보입니다. |
| `구성원_배포용/자가점검표_<이름>.xlsx` | **구성원 개인 배포용** 파일. 본인의 자가점검표 한 장만 담겨 있어 개별로 나눠줘도 다른 사람 정보가 노출되지 않습니다. |
| `구성원_배포용/자가점검표_템플릿(신규구성원용).xlsx` | 새로 합류한 구성원에게 배포할 빈 템플릿 (파란 칸만 있고 값은 비어 있음) |
| `ranking_dashboard.html` | 구성원 개인 자가점검표(.xlsx) 여러 개를 한 번에 업로드해 전체 통계와 1:1 리뷰 화면을 보여주는 오프라인 대시보드 (브라우저에서 파일을 직접 열면 됨, 서버 불필요) |

## 전체 프로세스

1. **자가점검표 배포 및 작성** — 관리자가 `구성원_배포용/자가점검표_<이름>.xlsx` 파일을 각자에게 나눠줍니다(메일·USB 등 오프라인 경로). 구성원은 자기 파일만 받으므로 다른 사람의 데이터를 볼 수 없습니다. 모든 항목(중점과제 1~3순위, 추가과제, 아쉬운 성과, 전문성 강화, AI 활용 등)에 **정량 목표 → 달성 결과 → 1~10점 자가평가**를 채운 뒤 파일을 저장해 관리자에게 회신합니다. (새 구성원은 `자가점검표_템플릿(신규구성원용).xlsx` 사용)
2. **대시보드에 일괄 업로드** — 관리자가 회신받은 `.xlsx` 파일들을 `ranking_dashboard.html`에 한 번에 선택해 올립니다. 브라우저 안에서 바로 읽어(외부 전송 없음) 전체 순위표와 그래프를 자동으로 만듭니다.
3. *(선택)* **마스터 워크북에도 보관** — 같은 파일 내용을 `성과_고과_시스템.xlsx`의 해당 `자가점검표_<이름>` 시트 B3:B42에 값 붙여넣기 하면, 엑셀에서도 동일한 점수로 계산되고 기록이 보관됩니다.
4. **팀장 조정점수 입력 (선택)** — 자가점수가 지나치게 후하거나 박하다고 판단되면, 대시보드 순위표의 "팀장조정" 칸(또는 마스터 워크북 `1on1_준비노트` 시트)에 -10~+10점을 입력합니다. 특별한 사유가 없으면 0으로 둡니다. 최종점수 = 자가점검 기준점수 + 조정점수(0~100 범위로 clamp).
5. **1:1 리뷰** — 대시보드에서 리뷰할 구성원을 선택해 "구성원 모드"로 전환한 뒤 노트북을 구성원에게 보여주고, 본인 점수·팀 비교·자가점검 상세 내용을 함께 보며 리뷰합니다. 조정점수가 있다면 "자가점검 기준 XX.X (팀장 조정 ±X)"로 구성원에게도 투명하게 표시됩니다. 리뷰가 끝나면 PIN으로 관리자 모드로 복귀합니다.

## 대시보드 사용법 (`ranking_dashboard.html`)

### 1) 데이터 불러오기
- **기본**: `구성원_배포용/자가점검표_<이름>.xlsx` 파일들을 파일 선택창에서 여러 개 한 번에 선택합니다. 각 파일의 '자가점검표' 시트를 브라우저가 직접 읽어 점수를 계산합니다 (SheetJS 등 외부 라이브러리·CDN 없이, ZIP+XML을 순수 JS로 해석).
- 이름이 같은 파일을 두 번 올리면 나중에 올린 파일로 덮어씁니다.
- **고급 · CSV 붙여넣기**: 마스터 워크북의 '계산_순위표'를 이미 계산해 둔 경우, 표를 복사해 붙여넣어도 됩니다 (이 경로는 구성원별 자가점검 상세 내용과 팀장 조정점수 입력을 지원하지 않습니다).
- **고급 · 가중치 조정**: 성과/역량/동료평가 비중과 역량 세부 가중치, 학점·추천 상한값을 화면에서 바로 바꿔볼 수 있습니다. 기본값은 마스터 워크북 '파라미터' 시트와 동일합니다.
- **팀장조정 칸**: xlsx 업로드로 표를 만들면 순위표의 "팀장조정" 열이 입력 가능한 칸으로 바뀝니다. 값을 바꾸면 즉시 재계산·재정렬됩니다.

### 2) 관리자 모드 / 구성원 모드
- **관리자 모드** (기본) — 전체 구성원의 순위표, 최종점수 비교, 성과/역량/동료 breakdown이 모두 보입니다.
- **구성원 모드** — 관리자가 "구성원 모드로 전환"에서 한 명을 선택하면, 그 사람의 화면(본인 최종점수·순위, 팀 평균/최고 대비 비교, 본인 breakdown, 자가점검 상세 목표/결과/점수, 본인이 추천한 동료)만 표시됩니다. **다른 구성원의 이름이나 점수는 화면 어디에도 나타나지 않습니다** — 업로드 원본 파일 목록과 CSV 붙여넣기 칸까지 함께 비웁니다.

데이터를 처음 불러오면 관리자 PIN(4자리, 선택)을 설정할 수 있습니다. 설정해두면 구성원 모드에서 관리자 모드로 되돌아갈 때 PIN을 확인하므로, 1:1 도중 노트북을 잠시 구성원에게 맡겨도 실수로 전체 순위표가 노출되지 않습니다.

> **중요**: 이 구분은 화면에 표시되는 내용을 제한하는 **UI 수준의 보기 제한**입니다. 별도 서버·로그인이 없는 단일 HTML 파일이므로, 브라우저 개발자 도구를 사용하면 메모리에 로드된 전체 데이터에 접근할 수 있습니다. 신뢰할 수 있는 사람(관리자 본인)이 노트북을 직접 조작하는 대면 1:1 상황에서 "다른 구성원 점수가 화면에 실수로 보이는 것"을 막는 용도로 설계되었으며, 이는 실제 접근 통제(서버 인증)를 대체하지 않습니다.

## 점수 산식

- **성과환산점수 (100점)** = AVERAGE(중점과제1~3 점수, 추가과제 점수, 아쉬운성과 점수, 기여도 점수, 성과도 점수) × 10 — 7개 정량 항목(1~10)의 단순 평균
- **역량환산점수 (100점)** = 전문성강화 점수(1~10→40점) + 학점환산(SKHU+mySuni, 상한 20학점→30점) + AI자가점수(1~10→30점)
- **동료환산점수 (100점)** = MIN(추천받은 횟수, 상한 4회) ÷ 4 × 100
- **자가점검 기준점수** = 성과환산×60% + 역량환산×20% + 동료환산×20%
- **최종점수** = MAX(0, MIN(100, 자가점검 기준점수 + 팀장 조정점수)) — 조정점수는 -10~+10, 기본값 0, 가중치 없이 그대로 더해집니다

마스터 워크북에서는 `파라미터` 시트의 노란 칸(가중치)과 `1on1_준비노트` 시트(조정점수)에서, 대시보드에서는 "고급 설정 — 점수 가중치 조정" 패널과 순위표의 "팀장조정" 칸에서 동일한 값을 조정할 수 있습니다.

> 왜 조정점수를 두었나: 모든 항목을 자가점검 정량점수로만 계산하면 편리하지만, 순수 자기신고이므로 점수를 후하게 매기는 유인이 생길 수 있습니다. -10~+10의 좁은 범위로 팀장이 최소한의 검수를 하도록 해 정량화의 장점(일관성, 투명성)은 유지하면서 부풀리기 위험을 줄였습니다. 특별한 근거가 없으면 0으로 두면 됩니다.

## 신규 구성원 추가

1. `구성원_배포용/자가점검표_템플릿(신규구성원용).xlsx`을 새 구성원에게 배포해 작성받습니다.
2. *(엑셀에도 보관하려면)* 마스터 워크북에서 `자가점검표_템플릿` 시트를 복제하고 시트명을 `자가점검표_<이름>` 형식으로 변경한 뒤, 회신받은 개인 파일의 B3:B42 값을 붙여넣고, `동료추천_집계`·`1on1_준비노트`·`계산_순위표` 표에 새 행을 추가해 윗 행의 수식을 복사합니다.
3. 대시보드에는 그 구성원의 `.xlsx` 파일을 업로드 목록에 추가하기만 하면 됩니다.

## 참고

- 동료 추천 사유, 아쉬운 성과 서술 등 정성 텍스트는 1:1 리뷰 시 참고자료(대시보드의 "자가점검 상세 내용" 카드, 마스터 워크북의 `1on1_준비노트` 시트)로 쓰이며, 점수 계산에는 반영되지 않습니다.
- 워크북과 `구성원_배포용/` 개인 파일에 들어있는 홍길동/김영희/이철수/박민수 데이터는 사용법을 보여주기 위한 예시이며, 실사용 시 모두 교체해야 합니다.
- `ranking_dashboard.html`은 완전히 오프라인으로 동작하며(외부 CDN·네트워크 요청 없음), 업로드한 파일은 이 브라우저 탭의 메모리에서만 처리되고 저장되거나 전송되지 않습니다. 탭을 닫거나 새로고침하면 사라집니다.
