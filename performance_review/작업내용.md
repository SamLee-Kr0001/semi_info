# 구성원 성과 자가점검 · 고과 순위산정 시스템 — 작업 내용 정리

완전 오프라인으로 동작하는 구성원 성과 자가점검 → 고과 순위산정 → 1:1 리뷰 시스템입니다.
Excel 워크북과 단일 HTML 대시보드만으로 구성되며, 서버·인터넷 연결이 필요하지 않습니다.

## 1. 폴더 구성

```
performance_review/
├── README.md                              # 사용법 안내 (프로세스, 점수 산식, 신규 구성원 추가 방법)
├── 작업내용.md                             # 이 문서 — 전체 작업 내역 정리
├── 성과_고과_시스템.xlsx                    # 관리자/HR 전용 마스터 워크북 (구성원에게 배포 금지)
├── ranking_dashboard.html                  # 오프라인 대시보드 (관리자 모드 / 구성원 모드, 1:1 리뷰용)
└── 구성원_배포용/
    ├── 자가점검표_템플릿(신규구성원용).xlsx    # 신규 구성원 배포용 빈 템플릿
    ├── 자가점검표_홍길동.xlsx                 # 개인별 자가점검표 (본인 것만 포함, 예시 데이터)
    ├── 자가점검표_김영희.xlsx
    ├── 자가점검표_이철수.xlsx
    └── 자가점검표_박민수.xlsx
```

마스터 워크북에는 전 구성원 시트·순위표가 모두 들어있어 그대로 배포하면 다른 사람 정보가 노출되므로,
`구성원_배포용/` 개인 파일을 따로 만들어 배포용과 관리용을 분리했습니다.

## 2. 전체 프로세스

1. **자가점검표 배포·작성** — 관리자가 `구성원_배포용/자가점검표_<이름>.xlsx`를 각자에게 배포(메일·USB 등). 구성원은 자기 파일만 받으므로 타인 데이터를 볼 수 없음.
2. **대시보드에 일괄 업로드** — 회신받은 `.xlsx` 파일들을 `ranking_dashboard.html`에 한 번에 선택해 올리면, 브라우저 안에서 바로 읽어 전체 순위표·그래프를 자동 생성.
3. *(선택)* **마스터 워크북에도 보관** — 같은 내용을 `성과_고과_시스템.xlsx`의 해당 시트에 값 붙여넣기 하면 엑셀에서도 동일하게 계산·기록.
4. **팀장 조정점수 / 추천가산점 확인** — 자동 계산된 기준점수에 필요 시 팀장이 소폭 조정점수를 더하고, 동료추천 가산점은 자동 반영.
5. **1:1 리뷰** — 대시보드에서 구성원을 선택해 "구성원 모드"로 전환, 본인 데이터만 보여주며 리뷰. PIN으로 관리자 모드 복귀.

## 3. 자가점검표 설계 — 전면 정량화

모든 항목을 **정량 목표 → 달성 결과 → 자가평가 점수(1~10)** 3단 구조로 통일했습니다.

- **성과(What)**: 중점과제 1~3순위, 추가과제, 가장 아쉬운 성과, 팀 기여도, 종합 성과 자가평가 — 총 7개 정량 항목
- **역량(How)**: 전문성 강화노력, SKHU/mySuni 수료 학점, AI 활용역량
- **동료평가(Peer)**: 본인 파트 1명 + 타 파트 1명 추천(이름+사유)

목표·결과 서술에는 가능한 숫자(%, 건수, 일수, 시간 등)를 포함하도록 안내했습니다.

## 4. 점수 산식

| 항목 | 산식 |
|---|---|
| 성과환산점수(100) | AVERAGE(중점과제1~3, 추가과제, 아쉬운성과, 기여도, 성과도) × 10 |
| 역량환산점수(100) | 전문성점수×40% + 학점환산(SKHU+mySuni, 상한 20학점)×30% + AI점수×30% |
| 동료환산점수(100) | MIN(추천받은 횟수, 상한 4회) ÷ 4 × 100 — 동료평가 20% 가중치에 반영 |
| **자가점검 기준점수** | 성과환산×60% + 역량환산×20% + 동료환산×20% |
| 팀장 조정점수 | −10 ~ +10, 기본값 0. 가중치 없이 그대로 가산. 자가점수 부풀리기 방지용 |
| 추천가산점 | 추천받은 횟수 × 1점, **상한 없음**. 동료환산점수(20% 가중치, 4회 상한)와 별개로 추가 가산 |
| **최종점수** | MAX(0, MIN(100, 자가점검 기준점수 + 팀장 조정점수 + 추천가산점)) |

가중치·상한값은 마스터 워크북 `파라미터` 시트(노란 칸) 또는 대시보드의 "고급 설정 — 점수 가중치 조정" 패널에서 바꿀 수 있습니다.

**팀장 정성평가(1~5점)는 두지 않습니다.** 처음에는 팀장이 성과/역량 항목에 정성 점수를 매기는 구조였으나,
"모든 항목을 정량화하라"는 요청에 따라 자가점검 정량 항목만으로 기준점수를 계산하도록 바꾸고,
이후 "자가점수 부풀리기가 우려된다"는 피드백을 받아 좁은 범위(-10~+10)의 조정점수만 별도로 추가했습니다.
정성평가 항목을 부활시키지 않고 조정점수라는 가벼운 안전장치로 대응한 것이 핵심 설계 결정입니다.

## 5. 오프라인 대시보드 (`ranking_dashboard.html`)

### 5.1 데이터 입력
- **기본 경로**: 구성원 개인 자가점검표 `.xlsx` 파일 여러 개를 한 번에 선택 업로드. 외부 라이브러리(SheetJS 등)나 CDN 없이, ZIP 중앙 디렉터리 파싱 + `DecompressionStream('deflate-raw')` + `DOMParser`만으로 xlsx 내부 XML을 직접 읽는 파서를 자체 구현했습니다.
- **고급 경로**: 마스터 워크북의 '계산_순위표'를 CSV로 붙여넣기 (상세 내용·팀장조정 입력은 미지원).
- **고급 설정**: 성과/역량/동료 가중치, 역량 세부 가중치, 학점·추천 상한값을 화면에서 바로 조정 가능(즉시 재계산).

### 5.2 관리자 모드 / 구성원 모드 (1:1 리뷰용 프라이버시 설계)
- **관리자 모드**(기본): 전체 순위표, 최종점수 비교, 성과/역량/동료 breakdown, 순위표에서 직접 팀장조정점수 입력.
- **구성원 모드**: 관리자가 한 명을 선택하면 그 사람의 화면(점수·순위, 팀 평균/최고 대비 비교, 자가점검 상세 목표/결과/점수, 본인이 추천한 동료)만 표시. **다른 구성원의 이름·점수는 업로드 파일 목록·CSV 입력창까지 포함해 화면 어디에도 남지 않도록** 처리했고, 헤드리스 브라우저로 DOM 텍스트를 직접 검사해 검증했습니다.
- 관리자 PIN(선택, 4자리)을 설정하면 구성원 모드→관리자 모드 복귀 시 확인을 요구. 단, 이는 서버 인증이 아닌 **UI 수준의 화면 보기 제한**임을 명시했습니다(개발자 도구로는 우회 가능).

### 5.3 디자인
사용자가 제공한 VoltAgent 스타일 디자인 시스템(다크 캔버스 `#101010`, 단일 그린 액센트 `#00d992`, Inter+SF Mono, 헤어라인 카드, 절제된 60px 헤드라인)을 그대로 적용했습니다.

### 5.4 투명성
팀장 조정점수·추천가산점은 절대 숨기지 않고, 관리자 테이블·breakdown 그래프·구성원 모드 화면 모두에서
"자가점검 기준 76.3 (팀장 조정 +1, 추천가산 +3)" 형태로 그대로 노출합니다.

## 6. 검증 방법

이 샌드박스 환경의 LibreOffice 헤드리스 재계산(recalc)이 제 워크북과 무관하게 동작하지 않는 환경 문제가 있어
(최소 재현: 빈 2셀짜리 xlsx도 동일하게 타임아웃), 아래 방법으로 정확성을 교차 검증했습니다.

- Excel 수식을 셀 단위로 감사(openpyxl로 재로드해 수식 문자열 확인)
- 동일한 계산 로직을 Python으로 별도 재구현(섀도우 계산)해 Excel 수식과 결과 비교
- 대시보드 JS의 계산 로직도 같은 방식으로 섀도우 계산과 대조
- 실제 생성된 `.xlsx` 파일을 헤드리스 Chromium(Playwright)에 업로드해 전체 파이프라인(파싱→계산→렌더링→모드 전환→PIN)을 종단 테스트

모든 예시 데이터(홍길동/김영희/이철수/박민수) 기준 Excel과 대시보드의 최종점수·순위가 정확히 일치함을 확인했습니다.

## 7. 알려진 제한 사항

- **팀장 조정점수/추천가산점의 존재**로 순수 자기신고 점수의 부풀리기 위험은 줄였지만, 완전히 제거하지는 못합니다.
- **동료추천 이름은 자유 텍스트**입니다(로스터 기반 드롭다운 검증 없음) — 오타·본인파트/타파트 오입력 가능성은 1:1/집계 단계에서 육안 확인이 필요합니다.
- **순위는 동점 처리 없는 엄격한 1~N위**입니다.
- **구성원 모드의 프라이버시는 UI 수준 제한**이며 서버 인증을 대체하지 않습니다(브라우저 개발자 도구로 우회 가능). 신뢰할 수 있는 관리자가 직접 노트북을 조작하는 대면 1:1 상황을 전제로 설계했습니다.
- 대상 조직 규모는 20명 내외를 기준으로 설계했습니다(그 이상 규모에서는 로스터 관리·업로드 파일 개수 증가에 대한 추가 UX가 필요할 수 있습니다).

## 8. 변경 이력 (요약)

1. 구성원 성과 자가점검표(정성+정량 혼합) + 고과 순위산정 워크북 최초 설계
2. 구성원용/관리자용 파일 분리, VoltAgent 디자인 시스템 적용, 대시보드 관리자/구성원 모드 + PIN 추가
3. 모든 자가점검 항목을 정량 목표→결과→1~10점 구조로 전면 개편, 팀장 정성평가(1~5점) 제거
4. 대시보드에 구성원 자가점검표 `.xlsx` 일괄 업로드 기능 추가 (오프라인 커스텀 xlsx 파서 자체 구현)
5. 자가점수 부풀리기 방지를 위한 팀장 조정점수(-10~+10) 재도입
6. 동료추천 가산점(추천 1회당 +1점, 상한 없음) 추가 — 기존 동료환산점수(20% 가중치)와 별개로 가산
