구성원 고과 순위 대시보드

구성원 자가점검표(.xlsx) 여러 개를 한 번에 올리면 전체 통계를 자동 계산합니다. 관리자 모드에서는 전체 순위를, 구성원 모드로 전환하면 선택한 한 사람의 데이터와 팀 대비 비교만 표시됩니다 — 다른 구성원의 개별 점수는 화면에 나타나지 않습니다.

STEP 1

구성원 자가점검표 일괄 업로드

구성원_배포용/자가점검표_<이름>.xlsx 파일들을 회신받은 그대로 모두 선택하세요. 이 페이지 안에서 바로 읽어 성과·역량·동료평가 점수를 계산합니다 (외부 전송 없음).

고급 설정 — 점수 가중치 조정

기본값은 성과_고과_시스템.xlsx의 '파라미터' 시트와 동일합니다. 값을 바꾸면 즉시 다시 계산됩니다.

고급 — 이미 계산된 순위표를 CSV로 붙여넣기

마스터 워크북의 '계산_순위표' 시트를 이미 계산해 둔 경우, 표를 복사해 여기에 붙여넣어도 됩니다.

이 페이지는 완전히 오프라인으로 동작하며 업로드한 파일은 이 브라우저 탭의 메모리에서만 처리되고 저장되거나 전송되지 않습니다. 구성원 모드는 화면에 표시되는 내용을 제한하는 화면 보기 제한 기능이며, 서버 인증을 대체하는 보안 장치는 아닙니다. 1:1 진행 중 노트북을 구성원에게 보여줄 때 사용하고, 자리를 비울 때는 관리자 PIN으로 보호하세요.
